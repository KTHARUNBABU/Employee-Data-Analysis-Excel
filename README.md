# Employee Data Analysis using Advanced Excel
## Project Overview
This project analyzes employee data using Advanced Excel techniques to derive meaningful business insights.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Conditional Formatting
- Slicers
- Dashboard Design
- Data Cleaning

## Dataset
Employee dataset containing:
- Employee ID
- Department
- Salary
- Experience
- Gender
- Performance Rating

## Key Analysis
- Department-wise employee count
- Salary distribution
- Gender analysis
- Performance analysis
- Experience trends

## Dashboard Features
- Interactive slicers
- Dynamic charts
- KPI indicators
- Automated summaries

## Project Outcomes
- Identified salary trends
- Department performance insights
- Workforce distribution analysis
